DATA PERSISTENCE
================================================================================

Bet Storage: /data/sports_plugin/bets.json
├─ Bet records with: id, date, league, game, bet_type, pick, odds, stake
├─ Result status: pending, win, loss, push
└─ P&L tracking per bet

Settings: /data/sports_plugin/settings.json
├─ Bankroll amount
├─ Unit size
├─ Kelly fraction (default 0.25)
└─ Favorite teams/leagues and alert settings

================================================================================
API REFERENCE (FOR DEVELOPERS)
================================================================================

Core Functions:

async analyze_betting_screenshot(photo_bytes, context_text="")
  → Dict with game, bet_type, books list, best_book

async calculate_bet_size(odds, bankroll_or_unit, method, confidence=None)
  → Dict with stake, recommendation, implied_prob

async log_bet_from_screenshot(photo_bytes, user_settings)
  → Dict with bet_id, bet record, success status

async log_bet_from_text(text, user_settings)
  → Dict with bet_id, bet record, success status

async resolve_bet(bet_id, result, pnl=None)
  → Dict with updated bet, message, success status

async calculate_stats(bets=None, period=None, league=None)
  → Dict with wins, losses, ROI, by_league breakdown, streak, etc.

Chart Functions:

async generate_pnl_chart(bets, period="all") → bytes (PNG)
async generate_win_rate_chart(bets) → bytes (PNG)
async generate_roi_chart(bets) → bytes (PNG)
async generate_unit_tracker(bets) → bytes (PNG)
async generate_bet_distribution(bets) → bytes (PNG)
